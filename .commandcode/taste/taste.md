# Taste Learnings

## Workflow & Communication
- Prefers the assistant to understand and discuss a concept or external context first before jumping into implementation in the current project. Don't assume reading local files is the right starting point. Confidence: 0.8
- Expects the assistant to ask clarifying questions before making assumptions about scope — e.g., "which project" or "where does that context live." Confidence: 0.8
- Expects cross-session memory — assumes the AI can recall and reference prior conversations without needing context re-explained. Gets frustrated when told the AI has no access to previous chats. Confidence: 0.85
- Prefers terse, minimal communication — gives short direct instructions and expects the assistant to work with whatever is provided rather than requesting lengthy explanations. Confidence: 0.8
